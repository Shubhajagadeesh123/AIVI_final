# AIVI – AI Visual Assistant for Visually Impaired People

AIVI (AI Visual Assistant) is an AI-powered, voice-first assistive application designed to help visually impaired users understand their surroundings, identify objects, navigate to destinations, remember previously observed objects and scenes, and request emergency assistance.

The application combines Artificial Intelligence, Computer Vision, Voice Interaction, Multilingual Support, Navigation, Memory Assistance, and Emergency Communication into a single accessibility-focused system.

# 📖 Project Overview

Visually impaired people may face difficulties while:

- Identifying objects around them
- Understanding their surroundings
- Navigating unfamiliar locations
- Avoiding obstacles
- Remembering where objects were placed
- Using applications that depend heavily on visual interfaces
- Getting assistance during emergency situations

AIVI is designed as a voice-first assistive system that uses a smartphone camera, microphone, AI services, location services, and audio feedback to provide useful information to the user.

The system is designed to reduce dependence on visual interfaces and allow users to interact with the application primarily through voice.

---

# ❗ Problem Statement

Traditional applications are often designed around visual interaction.

For a visually impaired person, tasks such as:

- Identifying an object
- Reading information
- Finding a destination
- Understanding nearby obstacles
- Remembering where an object was placed
- Requesting emergency help

can become difficult.

AIVI addresses these challenges by combining computer vision, conversational AI, voice interaction, navigation, memory, and emergency communication into one accessibility-oriented application.

---

# 🎯 Objectives

The main objectives of AIVI are:

1. Provide AI-based visual assistance.
2. Detect objects using the smartphone camera.
3. Describe relevant surroundings using AI.
4. Enable voice-based interaction.
5. Provide audio feedback to users.
6. Support multiple Indian languages.
7. Provide navigation assistance.
8. Provide obstacle warnings.
9. Store useful scene and object information for later queries.
10. Provide emergency SOS functionality.
11. Support Bluetooth audio devices.
12. Provide an accessible mobile-friendly interface.
13. Reduce dependence on visual interaction.
